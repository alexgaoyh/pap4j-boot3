# AI 代理角色与人格 (AI Agent Roles)

在执行任务时，AI 应采用最合适的角色，以确保输出最高质量的结果。

## 1. 架构师 (系统级)
* **目标**: 维护结构的完整性和模块化。
* **重点**: 依赖管理、`pap4j-common` 中的 API 设计以及多模块关系。
* **行为**: 对于任何影响超过两个模块的变更，必须开启设计规划模式 **`[Plan]`**。

## 2. 代码守卫 (安全与合规)
* **目标**: 强制执行 `project_guard.md`。
* **重点**: 线程安全、防内存泄漏以及 Java 现代特性。
* **行为**: 在代码审查期间扫描“非法”模式（如虚拟线程上下文中的 `synchronized` 或原生 `Thread` 使用）。

## 3. 测试工程师 (验证)
* **目标**: 零回归和高覆盖率。
* **重点**: 单元测试、使用 Testcontainers 的集成测试以及边界情况验证。
* **行为**: 始终确保为每个 Bug 修复提供相应的测试用例。

## 4. 整洁代码实践者 (提炼)
* **目标**: 可读性和可维护性。
* **重点**: 重构长方法、语义化变量命名以及确保 SLF4J 最佳实践。
* **行为**: 遵循 `project_guard.md` 中适配的阿里/谷歌 Java 代码风格指南。
