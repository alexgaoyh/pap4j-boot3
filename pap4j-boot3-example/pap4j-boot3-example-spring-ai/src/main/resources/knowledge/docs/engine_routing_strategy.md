## 引擎分发策略（Engine Routing Strategy）

> **元数据**
> - **组件/引擎**：Hybrid
> - **分类/模块**：核心语法
> - **类型**：infrastructure
> - **关键字**：路由, $, 引擎区分, 逻辑入口



系统的表达式引擎分为两种：JsonPath 引擎和 QLExpress 引擎。系统会在执行表达式之前，先对表达式进行 trim 去空白处理，然后判断其首字符是否为 `$` 美元符号。如果表达式以 `$` 开头，系统会强制将其路由到 JsonPath 引擎执行；否则，将由 QLExpress 引擎负责执行。

这个判断是系统的核心入口逻辑，直接决定了后续的执行路径。

**示例**：
表达式 `$.id` 以 `$` 开头，因此会由 JsonPath 引擎解析并提取 JSON 数据中的 id 字段。

**常见错误**：严禁在以 `$` 开头的表达式中混入 QLExpress 函数语法，例如 `$.id + DIV2(1,2)` 是不合法的，会导致引擎解析失败。两种引擎的语法不能混用，路由规则完全由表达式的首字符决定。

**例外**：在 QLExpress 脚本内部可通过 [JSON_PATH](function_json_path.md) 函数有控制地调用 JsonPath 能力，这是一种受支持的融合使用方式。
