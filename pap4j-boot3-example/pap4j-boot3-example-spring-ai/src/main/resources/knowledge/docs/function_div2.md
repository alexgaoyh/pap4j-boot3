## DIV2 — 高精度舍入除法函数

> **元数据**
> - **组件/引擎**：QLExpress
> - **分类/模块**：算术运算
> - **类型**：自定义函数
> - **关键字**：除法, 精度, 四舍五入, 转化率



DIV2 是 QLExpress 引擎中执行高精度安全除法的专用函数。它对除法结果强制保留 2 位小数，采用四舍五入（HALF_UP）舍入模式。在所有涉及百分比、点击率、转化率、费率等业务计算场景中，DIV2 是直接使用 `/` 运算符的强制替代品。关于标准四则运算的语法和注意事项详见 [arithmetic_operators.md](arithmetic_operators.md)。

**函数签名**：`DIV2(numerator, denominator)`
- 第一个参数 numerator 是分子，类型为数字。
- 第二个参数 denominator 是分母，类型为数字。

**使用示例**：
```ql
DIV2(json.click, json.view)
```
这段代码计算点击率（点击次数除以曝光次数），结果会自动四舍五入保留两位小数。例如点击 10 次、曝光 30 次，结果会返回 0.33。

**常见错误**：在计算百分比或比例时，直接使用 `/` 会因浮点精度问题导致结果小数位过长，例如 `1 / 3` 会产生 0.3333333... 这样的结果。必须改用 `DIV2(1, 3)`，结果会规范地返回 0.33。计算转化率、单价、费率时同样适用这条规则。
