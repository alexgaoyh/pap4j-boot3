## LIST_JOIN — 集合元素拼接函数

> **元数据**
> - **组件/引擎**：QLExpress
> - **分类/模块**：集合/列表操作
> - **类型**：自定义函数
> - **关键字**：join, 拼接, 列表转字符串



LIST_JOIN 是 QLExpress 引擎中将列表中的所有元素连接成一个字符串的函数。它常用于将标签列表、分类列表、ID 列表等集合数据，以指定分隔符拼接为单个字符串输出，便于展示或存储。

**函数签名**：`LIST_JOIN(list, sep)`
- 第一个参数 list 是待拼接的列表。
- 第二个参数 sep 是元素之间的分隔符字符串，默认值为逗号 `,`，可以省略。

**使用示例**：
```ql
LIST_JOIN(json.tags, '#')
```
这段脚本将 tags 列表中的所有标签用 `#` 号连接成一个字符串。例如标签列表 `['Java', 'Spring', 'AI']` 会被拼接为 `'Java#Spring#AI'`。

**安全特性**：当传入的 list 为空列表（没有任何元素）时，LIST_JOIN 会返回空字符串 `''`，而不是 null。这个行为保证了后续对返回值的字符串操作不会因 null 而抛出异常。
