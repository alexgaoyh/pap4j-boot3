## 构建复杂 Map 对象（Map Construction）

> **元数据**
> - **组件/引擎**：QLExpress
> - **分类/模块**：核心语法
> - **类型**：语法特性
> - **关键字**：Map, 对象构建, 嵌套结构



在 QLExpress 引擎中，可以使用类似 JSON 的语法直接在脚本里构建嵌套的 Map 对象，并将其作为脚本的返回结果。这种写法非常适合需要将多个字段组合重新封装成结构化结果的场景。

Map 对象使用花括号 `{}` 定义，键值对之间用冒号 `:` 分隔，多个键值对之间用逗号 `,` 分隔。值可以直接引用 json 对象中的字段，也可以是嵌套的 Map 对象。

**使用示例**：
```ql
res = { "id": json.id, "info": { "tag": "new" } };
return res;
```
这段脚本构建了一个包含两个字段的 Map 对象：外层的 `id` 字段直接取自 json 数据，内层的 `info` 字段是一个嵌套 Map，其中 `tag` 值被硬编码为字符串 'new'。最后通过 `return res` 将构建好的对象返回。

**常见错误**：
1. 定义 Map 对象必须使用花括号 `{}`，不能使用其他语法。
2. 脚本最后一条语句通常需要使用 `return` 关键字显式返回，否则可能导致返回值为空。
3. `return` 关键字和返回值之间必须有空格，严禁粘连书写。
