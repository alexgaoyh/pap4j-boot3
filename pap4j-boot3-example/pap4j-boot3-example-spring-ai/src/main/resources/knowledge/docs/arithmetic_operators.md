## 基础算术运算符（Arithmetic Operators）

> **元数据**
> - **组件/引擎**：QLExpress
> - **分类/模块**：算术运算
> - **类型**：standard_operator
> - **关键字**：加, 减, 乘, 除, 优先级, 结合性



QLExpress 引擎支持标准 Java 语法的四则运算，包括加法 `+`、减法 `-`、乘法 `*` 和除法 `/`。运算符的优先级遵循数学常规：括号 `()` 的优先级最高，其次是乘法和除法，最后是加法和减法。减法和除法具有左结合性，即从左到右依次计算。

**示例**：
```ql
a * (b + c) - d / e
```
这段表达式先计算括号内的 `b + c`，再乘以 `a`；同时独立计算 `d / e`，最后将两个结果相减。

**重要警告**：在涉及金额、比率、转化率等业务计算时，不应直接使用 `/` 运算符进行除法。因为直接除法会产生浮点精度问题，导致结果小数位不可控。应当优先使用 DIV2 函数代替，DIV2 能自动保留两位小数并进行四舍五入，是业务计算的安全替代方案。详见 [function_div2.md](function_div2.md)。
