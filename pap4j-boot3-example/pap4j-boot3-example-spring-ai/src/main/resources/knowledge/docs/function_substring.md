## SUBSTRING — 字符串截取与脱敏函数

> **元数据**
> - **组件/引擎**：QLExpress
> - **分类/模块**：字符串处理
> - **类型**：自定义函数
> - **关键字**：截取, substring, 脱敏, 隐藏

### 💡 核心介绍
SUBSTRING 是 QLExpress 引擎中按索引截取字符串片段的函数。它常用于对敏感信息进行掩码脱敏处理，例如隐藏手机号中间的数字、隐藏身份证号码的部分字符、截取邮箱前缀等场景。

### 📝 语法签名
`SUBSTRING(s, start, end)`
- 参数 s 是原始字符串。
- 参数 start 是起始索引，从 0 开始计数，截取时包含该位置的字符。
- 参数 end 是结束索引，截取时不包含该位置的字符，遵循左闭右开原则。
- end 参数可以省略，省略时默认截取到字符串末尾。

### 💻 推荐代码示例（手机号脱敏）

```ql
SUBSTRING(json.phone, 0, 3) + '****' + SUBSTRING(json.phone, 7)
```
这段脚本保留手机号的前 3 位和后 4 位，中间用四个星号代替，实现手机号脱敏。例如手机号 '13812345678' 经处理后会变成 '138****5678'。

### ⚠️ 避坑指南与常见错误
end 索引必须大于或等于 start 索引，且不能超过字符串的总长度，否则会抛出字符串索引越界异常（StringIndexOutOfBoundsException）。在使用前建议先确认字段长度，或配合 [ISBLANK](function_isblank.md) 进行空值前置检查。
