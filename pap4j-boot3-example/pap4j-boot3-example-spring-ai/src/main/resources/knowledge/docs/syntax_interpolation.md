## 变量插值占位符（Variable Interpolation）

> **元数据**
> - **组件/引擎**：QLExpress
> - **分类/模块**：核心语法
> - **类型**：语法特性
> - **关键字**：${}, 动态替换, 占位符



QLExpress 引擎支持在脚本文本中使用 `${varName}` 语法作为动态变量的占位符。在脚本实际执行之前，系统会将所有的 `${varName}` 占位符替换为对应的外部动态变量值，这个替换过程发生在脚本被解析和执行之前。

这种机制允许将一些在运行时才能确定的参数（如阈值、限额、动态配置值等）从外部注入到脚本中，而不需要硬编码在脚本里。

**使用示例**：
```ql
json.score > ${minScore}
```
这段脚本在执行时，`${minScore}` 会被替换为外部传入的实际最小分数值，例如替换为 60 后，脚本变为 `json.score > 60`，然后再进行比较计算。

**常见错误**：`${varName}` 占位符只用于注入来自外部的动态变量，不能用于引用脚本内部定义的局部变量。例如在脚本中用 `a = 10` 定义了局部变量 `a` 后，不能用 `${a}` 来引用它，应该直接写变量名 `a`。混用会导致占位符无法被正确替换，产生脚本解析错误。
