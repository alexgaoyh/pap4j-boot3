## TRIM — 去除首尾空格函数

> **元数据**
> - **组件/引擎**：QLExpress
> - **分类/模块**：字符串处理
> - **类型**：自定义函数
> - **关键字**：trim, 去空格, 清洗

### 💡 核心介绍
TRIM 是 QLExpress 引擎中用于去除字符串首尾空白字符的函数。它会清除字符串开头和结尾的空格、制表符等空白字符，常用于对用户输入的数据进行清洗和规范化，确保字段值的整洁。

### 📝 语法签名
`TRIM(s)`
- 参数 s 是待处理的字符串。

### 💻 推荐代码示例

```ql
TRIM(json.nickname)
```
这段脚本去除昵称字段两端的多余空格，例如字符串 '  张三  ' 会被清洗为 '张三'，可以放心地用于后续的比较或存储操作。

### ⚠️ 注意事项
TRIM 函数只处理字符串首尾的空白字符，不会移除字符串中间位置的空格。例如字符串 '张  三' 经过 TRIM 处理后仍然是 '张  三'，中间的空格不受影响。如果需要去除中间的空格，需要使用其他字符串替换方式处理。
